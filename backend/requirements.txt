# --- Sprint 3B: pinned to fix a torch/numpy/transformers ABI conflict -----
# Root cause (reproduced and confirmed): torch<2.3 wheels are compiled
# against NumPy's 1.x C-API and raise "_ARRAY_API not found" under
# numpy>=2.0. Leaving numpy/scipy/torch unpinned let pip resolve numpy
# 2.5.1 + scipy 1.18.0 (which *requires* numpy>=2.0.0) alongside a
# pre-existing/older torch, producing exactly that crash on import of
# HuggingFaceEmbedding.
#
# A second, independent issue: leaving transformers unpinned resolves to
# a version that requires torch>=2.4 and silently corrupts itself
# (NameError: name 'torch' is not defined) when that floor isn't met.
#
# Fix: bump torch to a numpy-2-compatible release, and pin
# transformers/huggingface-hub/tokenizers/sentence-transformers to a
# deliberately conservative, known-good combination rather than letting
# them float to the newest available. Verified together: clean
# `pip install`, `pip check` reports no conflicts, and
# `from llama_index.embeddings.huggingface import HuggingFaceEmbedding`
# imports without error.
numpy==2.1.3
scipy==1.14.1
torch==2.4.1
transformers==4.44.2
huggingface-hub==0.24.6
tokenizers==0.19.1
sentence-transformers==3.0.1
