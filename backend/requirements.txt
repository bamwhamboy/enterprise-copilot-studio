# --- Embedding model: fastembed (ONNX Runtime), not PyTorch ---------------
# Replaces the original torch + sentence-transformers + transformers +
# llama-index-embeddings-huggingface stack (see git history for the
# extensive ABI-conflict pinning that stack required) after confirming
# in production that it exceeds Render's 512MB instance limit during
# model loading -- PyTorch's own import/runtime overhead (300-500MB+,
# independent of any model) is the dominant memory cost there, not the
# model weights themselves.
#
# fastembed runs the *same* BAAI/bge-small-en-v1.5 model (same 384-dim
# embedding space -- EMBEDDING_DIMENSION below is unchanged, so the
# existing Qdrant collection schema needs no migration) via a quantized
# ONNX export (qdrant/bge-small-en-v1.5-onnx-q, 67MB vs. the original
# ~130MB float32 weights) through ONNX Runtime instead of PyTorch --
# confirmed via a clean install that this pulls in only numpy +
# onnxruntime as its heavy dependencies, not torch. See
# app/knowledge_engine/embeddings/embedding_model.py for the retrieval
# quality trade-off notes (small, from quantization -- not from a
# different/smaller model).
fastembed==0.8.0
llama-index-embeddings-fastembed==0.6.0
numpy==2.5.1
tokenizers==0.23.1
